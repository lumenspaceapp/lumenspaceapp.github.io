# Lumen Notes

A Notion-style workspace with frosted-glass panels, an animated gradient background and smooth motion. Plain HTML, CSS and JavaScript — no build step, no install.

## Use it

Open the live site (GitHub Pages), or open `index.html` locally.

## Features

- Nested pages in a sidebar with drag-to-reorder, favorites, trash with restore
- Blocks: text, headings, bulleted/numbered/to-do lists, toggles, quotes, callouts, dividers, code with highlighting, images, sub-pages, page mentions
- `/` command menu, Markdown shortcuts (`#`, `-`, `1.`, `[]`, `>`, ```` ``` ````, `**bold**`, `` `code` ``), drag handles, block colors
- Databases with table, board (kanban) and gallery views, typed properties, sorting, search and a side panel for each row
- Ctrl+K search across all page content, page outline with word count, home dashboard, templates
- Light/dark/system theme, accent color, adjustable glass blur, focus mode
- Export pages as Markdown; back up or restore the whole workspace as JSON

## Where data lives

Everything is saved in your browser's local storage. Each person and each browser has its own workspace — pages are **not** shared between visitors. Use **Settings → Backup** to export a workspace and import it somewhere else.

| Toggle sidebar | Ctrl \ |

| Indent / outdent | Tab / Shift Tab |
| Duplicate block | Ctrl D |
